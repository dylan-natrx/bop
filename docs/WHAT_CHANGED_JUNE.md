## 1. The data, in one breath

The raw measurements did not change. The **scoring functions** did, and two flag definitions tightened.

- **Dissolved-oxygen scoring got stricter**, so many middle-of-the-pack bay sites dropped.
- **Salinity scoring is now fit to local reality** (oysters survive in the fresher upper Hudson), so Hudson sites rose.
- **Top tier is unchanged:** Arthur Kill #1 (0.87), Living Breakwaters cluster #2–7, Wolfe's Pond #8, Conch Basin #9.
- **Erosion flag** now means ≥1 ft/yr: **8 sites** (was 23). **Wave flag** ≥3 ft: **22 sites** (was 41).
- **Data-support tiers** shifted: 8 / 23 / 15 / 14 / 18 (Robust / Strong / Adequate / Limited / Sparse).
- The walkthrough's bright "qualifying" set is now **18 sites**.

Full technical detail lives in the session analysis and `memory/project_june_data_update.md`.
